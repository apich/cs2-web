# 03 · 客户端（client/）

客户端运行在浏览器，负责 3D 渲染、输入捕获、HUD/UI、音频与特效，并通过 WebSocket 与权威服务器交互。入口是 `main.js`。

## 1. 入口 — main.js

`client/main.js`（583 行）是客户端中枢，既初始化所有子系统，又承载游戏主循环与网络收发。

### 初始化顺序
1. 创建 `THREE.WebGLRenderer`（高性能、无抗锯齿）、`scene`（主场景）与 `gunScene/gunCamera`（第一人称武器层，独立渲染保证枪模永不被墙体遮挡）。
2. 实例化大量子系统（见下表）。
3. 绑定 DOM 事件：`start-button`/`join-button`、菜单/选队/选枪、指针锁、鼠标移动、灵敏度/音量/画质、邀请、HMR 热更新等。
4. `requestAnimationFrame(frame)` 启动渲染循环。

### 关键函数
- `loadGame(audioReady)`：按 `download → scene → connect` 三阶段加载资源（地图、模型、皮肤、音频），并行 `loadModels/createMapScene/loadAgent/loadSkin`，再 `initPhysics`、编译着色器。
- `start(joinExisting)` / `connect(joinExisting)`：建立 WebSocket、发送 `join`、处理 `welcome`/`snapshot`/`purchase`/`error` 等回包。
- `handleSnapshot(data)`：解析权威快照，更新自身状态、`actors`（远端角色）、HUD、特效、音频，处理 `relocated`/`death`/`respawn` 等迁移。
- `handleEvent(e)`：分发出事件（`shot`/`hit`/`kill`/`flash`/`explosion`/`grenade_thrown` 等）到特效、音频、UI。
- `currentInput()`：聚合键鼠/触屏生成上行输入；`localShoot(input, dt)`：本地预渲染射击（弹道、曳光、枪口、后坐力），并带 `shotId` 上行等服务器确认。
- `controlAction(action, {pressed})`：按键动作分发（开火、开镜、切枪、购买、投掷、丢枪、检视、计分板、菜单）。
- `frame(now)`：主循环——60Hz 移动预测、30Hz 输入上行、2s 一次 ping、蹲伏插值、相机位置/朝向、观战、武器渲染、远端角色更新、HUD 刷新、双场景渲染。

## 3. 渲染结构

- **双场景渲染**：`scene`（世界 + 玩家）先渲染；`gunScene`（`ViewWeapon` 单独挂载）后渲染并 `clearDepth()`，保证第一人称枪模贴脸不被裁切。开镜全屏镜（`fullScope`）时跳过武器层。
- **FOV 换算**：CS 的 4:3 基准水平 FOV 经 `cs2FovToVertical` 转为 Three.js 垂直 FOV，开镜缩放多档（AWP 90/40/10）。
- **后坐力视觉**：`clientRecoil`（`createRecoilState`）+ `applyRecoilKick`，通过 `VIEW_RECOIL_TRACKING` 拆分「镜头跟随」与「准星偏移」。

## 4. 输入子系统

- `controls.js`（`GameControls`）：监听键鼠、`requestPointerLock` 鼠标锁定、可重绑定键位、冲突交换。
- `touch-controls.js`（`TouchControls`）：手机多指摇杆 + 滑动瞄准 + 战斗按钮（左右键投掷强弱）。
- `main.js` 的 `inputCaptured()` 判断输入是否被游戏捕获（鼠标锁或触屏激活）；`gameSurfaceActive()` 综合判断菜单是否盖住。
