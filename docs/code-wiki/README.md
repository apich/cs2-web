## 项目速览

- **名称**：`dust2-web`（README 标题「DUST II · 网页对战」）
- **类型**：浏览器端第一人称射击（FPS），经典竞技场 Dust II 的网页实现
- **技术栈**：
  - 前端：**Three.js**（WebGL2 渲染）+ **three-mesh-bvh**（空间碰撞查询）+ 原生 Vite HMR
  - 后端：**Node.js + ws**（WebSocket 实时通信）
  - 构建：**Vite**
- **架构模式**：权威服务器（Authoritative Server）+ 带预测/插值的瘦客户端
- **入口文件**：
  - 服务端：`server/index.js`
  - 客户端：`client/main.js`
  - 页面：`index.html`
- **运行门槛**：Node.js >= 22.12.0，支持 WebGL2 的现代浏览器
