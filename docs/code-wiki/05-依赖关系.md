# 05 · 依赖关系

## 1. npm 依赖

见 [package.json](../../package.json)。

| 依赖 | 版本 | 类型 | 用途 |
| --- | --- | --- | --- |
| [three](https://threejs.org/) | 0.185.1 | dependencies | WebGL2 3D 渲染引擎 |
| [three-mesh-bvh](https://github.com/gkjohnson/three-mesh-bvh) | 0.9.14 | dependencies | 网格 BVH 加速结构，用于地图碰撞与射线查询 |
| [ws](https://github.com/websockets/ws) | 8.21.3 | dependencies | WebSocket 服务器（`server/index.js`） |
| [vite](https://vitejs.dev/) | 8.2.2 | devDependencies | 前端构建与开发服务器（HMR） |

- **运行时要求**：Node.js `>=22.12.0`（`package.json` engines 声明）。
- 无其他后端框架——HTTP 层直接用 `node:http` 原生模块，WebSocket 用 `ws`。

**关键约束**：
- `client/` 与 `server/` 之间**无直接 import**，仅共享 `shared/`，通信只经 WebSocket。
- `shared/` 不得 import `client/` 或 `server/`（保持无环、可被两端安全复用）。

## 3. 核心数据流对象

### 上行 `input`（客户端 → 服务端）
由 `sanitizeInput` 校验，核心字段：`seq`、`forward/right`、`yaw/pitch`、`jump/jumpId`、`crouch`、`walk`、`fire/fire2`、`reload/reloadId`、`interact`、`slot`、`utilityId`、`zoomLevel`、`shotId`、`shotWeapon`、`viewTime`、`moves`、`moveId`。

### 下行 `snapshot`（服务端 → 客户端）
完整房间状态：`players`（位置/朝向/血量/武器/弹药/命中/回合数据）、`match`、`round`、`scores`、`time`、`bomb`、`grenades/smokes/fires/decoys`、`droppedWeapons`、`defuseKits`、`events`、`seats`、`hostId`、`desiredBots/botCount`。

### 事件 `event`（`type` 字段）
`shot`、`hit`、`kill`、`grenade_thrown`、`explosion`、`flash`、`fire_started/failed/extinguished`、`bomb_planted/defused/exploded`、`weapon_dropped/picked_up`、`kit_picked_up`、`host_changed`、`match_end` 等。事件带去重 `id`。

> 完整消息协议见 [server/PROTOCOL.md](../../server/PROTOCOL.md)。

## 4. 外部资源依赖

运行时所需的**大体积素材**（3D 地图、模型、贴图、音效）不在 git 仓库中，通过 `npm run assets:fetch` 从 CDN 拉取，清单与校验见 `config/assets-lock.json`。详见 06 运行与部署及仓库根 [docs/ASSETS.md](../../ASSETS.md)。

## 5. 构建与 QA 工具依赖（scripts/）

`scripts/` 下为开发/构建/QA 工具，非运行时依赖：
- `fetch-assets.mjs` / `build-asset-manifest.mjs` / `build-asset-lock.mjs`：资源抓取与清单生成。
- `map-build.py` / `map-fetch.py` / `map-optimize-*.mjs/py` / `map-validate.mjs`：地图构建/优化/校验。
- `extract-*.mjs`：从 CS2 数据提取弹道/UI/瞄准镜/精度/材质。
- `playwright-*.js` / `qa-*.mjs`：Playwright 与 Node 驱动的端到端 QA。
- `deploy/`：systemd 服务、Nginx 路由、发布打包脚本。
