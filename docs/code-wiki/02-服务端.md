## 2. index.js — 服务器入口

`startGameServer({ port, host, staticDir, rules })` 是唯一对外启动函数。

### 启动流程
1. `loadPhysics()`：读取 `public/assets/map/collision.json`（碰撞三角网）与 `penetration-materials.u8`（穿透材质），调用 `initPhysics(positions, materials)` 建立 `three-mesh-bvh` 空间结构。
2. 创建 HTTP 服务器：静态托管 `dist/`（构建产物）与 `public/`（素材），提供 `/health` 健康检查。
3. 创建 WebSocket 服务器，路径 `/ws`，启用 `perMessageDeflate` 压缩。
4. 启动两个定时器：
   - **tick 定时器**（1/TICK_RATE = 33ms）：遍历所有房间 `room.tick(dt)`，每 `TICK_RATE/SNAPSHOT_RATE` 个 tick 广播一次 `snapshot()`。
   - **心跳定时器**（15s）：ping/pong 与超时清理。

### 消息路由（socket 'message'）
对每条消息做**令牌桶限流**（`socket.tokens`）与 **JSON 校验**（`msg.type` 白名单）。支持的消息类型：

| 类型 | 处理 |
| --- | --- |
| `ping` | 回 `pong`（含 `serverTime`）用于计算 RTT |
| `listRooms` | 返回有玩家的房间列表 |
| `join` | 加入/创建房间，回 `welcome` + 初始 `snapshot` |
| `input` | 转发到 `room.receiveInput` |
| `takeBot` / `takeSeat` / `setSeatBot` | 接管 BOT / 换席位 / 增减人机 |
| `setBots` | 房主调整 BOT 数量 |
| `dropWeapon` | 丢枪 |
| `equipSkin` / `equipAgent` | 装备皮肤 / 探员 |
| `buy` / `refund` | 购买 / 退款 |

### 关键函数
- `joinSettings(msg)`：校验并清洗加入参数（名称、房间码、模式、阵营、BOT 数、主武器、皮肤/探员装载、移动协议）。
- `send(socket, value)` / `error(socket, code, message)`：下行封装。

## 3. game.js — GameRoom 权威模拟

`export class GameRoom` 是核心类，每个房间实例化一个。`export const TICK_RATE/SNAPSHOT_RATE/RULES`；`export function sanitizeInput/directionFromAngles/rayHitPlayer/applyArmorDamage`。

### 3.1 输入清洗与命中盒（模块顶部函数）
- `sanitizeInput(message)`：把上行 input 字段类型/范围清洗为安全的权威输入（yaw/pitch 归一化，`shotId/moveId/jumpId/reloadId` 校验）。
- `directionFromAngles(yaw, pitch)`：朝向角 → 单位向量。
- `rayHitPlayer(origin, direction, player, maxDistance)`：**三段立体命中盒**判定，返回 `{ distance, headshot }`：
  1. 头部/头盔球体（半径 0.23）
  2. 上身 AABB（双肩/手臂拓宽至 ±0.38 消除空洞）
  3. 下肢 AABB
  命中盒随玩家 `yaw` 旋转，站/蹲高度分别为 1.80 / 1.10。
- `applyArmorDamage(rawDamage, player, {...})`：护甲减伤计算（含头盔判断）。

### 3.2 GameRoom 构造与状态
- `constructor(code, { mode, bots, clock, rules, traceBullet })`：初始化 `players`（Map）、`clients`（socket）、`match`/`round`/`scores`/`teamSides`、`bomb`、`grenades`（GrenadeSimulation）、`droppedWeapons`、`poseHistory`（位置回溯，供延迟补偿）。

### 3.3 房间/席位/玩家管理
- `addHuman(socket, settings)` / `removePlayer(id)` / `makePlayer(id, name, team, bot, primary)` / `ensureBots()` / `pickSpawn(team)`。
- `takeSeat(id, team, seat)` / `setSeatBot(id, team, seat, enabled)` / `freeSeat(team)` / `roomSeats()`。
- `setBots(id, value)`：仅房主（`hostId`）可调。
- `emit(type, fields)`：追加事件（上限 300 条滚动）。

### 3.4 战斗逻辑
- `receiveInput(id, message)`：入口，校验 `seq`、`bodyId`/`lifeId`，写入移动流/射击队列/交互意图。
- `fireQueued(player)`：按时间窗口处理带 `shotId` 的显式射击命令（配合移动流确认）。
- `fire(p, input, command)`：核心开火判定——后坐力、散射抽样（`accuracyForShot`+`sampleShotDirection`+`shotRng`）、多弹丸、伤害衰减、`traceBullet` 穿透、命中结算、击杀反馈。
- `swingKnife(p, input, command)`：近战攻击（重击/背刺判定）。
- `damagePlayer(...)` / `kill(...)`：伤害与击杀（掉落拆弹器、死斗胜利判定）。
- `reload(p)` / `commitReload(p)` / `cancelReload(p)` / `finishReload(p)`：换弹状态机（含霰弹枪逐发装填）。
- `selectSlot(player, slot, utilityId)` / `equipSkin` / `equipAgent`。
- `pickupWeapon(p, automatic)` / `dropWeapon(id, death)` / `refundable` / `refund`。

### 3.5 购买与经济
- `buyStatus(p)`：判定是否可购买（存活、阶段、时间、出生区范围、阵营清单）。
- `buy(id, rawWeapon)`：校验后扣款、写入 `inventory`/`purchases`（本回合可退款收据）。

### 3.6 爆破与回合状态机
- `maybeStart()` / `startRound()` / `endRound(team, reason)` / `endMatch()`：回合与比赛流转。
- `bombIntent(p, input)`：判定安放/拆除意图。
- `stepBomb(dt)`：C4 状态机（携带 → 安放中 → 已安放 → 爆炸/拆除）。
- `dropBomb(p)` / `siteAt(p)`：炸弹掉落与包点检测。

### 3.7 手雷编排
- `captureGrenadeInput(p, input)` / `stepGrenade(p)`：按住准备、模式判定（远投/低抛/中投）、松手投出、取消。
- `explodeGrenade` / `burnPlayers` / `flashGrenade` / `pickupKits`：爆炸（高爆/火焰/闪光）结算。

### 3.8 BOT AI 编排
- `nearestNav(point)` / `planPath(p, goal)` / `chooseBotGoal(p)` / `botInput(p, dt)`：导航、目标选择、输入合成。
- 依赖外部模块：`bot-perception`（感知）、`bot-combat`（战斗）、`bot-utility`（投掷）、`bot-tactics`（战术目标）、`bot-aim`（瞄准）、`bot-trajectory`（轨迹预演）、`bot-lineups`（投点）。

### 3.9 tick 主循环
- `tick(dt = 1/TICK_RATE)`：每帧对所有玩家执行——输入归一化、目标锁定/交互、手雷取消、射击队列、换弹、拾取，然后 `grenades.tick(dt)`、BOT 输入合成、物理步进（`stepPlayer`）、玩家碰撞（`resolveAllPlayerCollisions`）、`stepBomb`、`flushRecoil`、击杀/回合结算。
- `snapshot({ drainEvents })`：序列化房间完整状态（玩家、比分、回合、炸弹、投掷物、掉落物、事件、席位、BOT 数等），供下行广播。

## 4. grenades.js — 投掷物模拟

`export class GrenadeSimulation`（86 行起）：管理投掷物生命周期与效果。

- 辅助函数：`pointToSegmentDistance`、`segmentIntersectsSmoke`。

## 6. 战斗系统支撑

- `bullet-penetration.js`：`export function traceBullet(...)`，沿弹道做世界射线，处理薄掩体穿透、贯穿数、穿透后伤害衰减。
- `dropped-weapons.js`：`export class DroppedWeapons`，管理掉落在地的武器（含皮肤、剩余弹药）。
- `performance-metrics.js`：`export class ServerPerformance`，记录 tick 耗时与延迟，供 `/health` 输出。
