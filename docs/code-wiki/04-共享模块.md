# 04 · 共享模块（shared/）

`shared/` 存放**客户端与服务端共用的**数据与算法。这是本项目「双端确定」的核心——弹道、移动物理、武器数值只在 `shared/` 定义一次，两端 import 同一份，避免漂移。

## 2. 关键数据表

### weapons.js — 武器主表
- `WEAPONS`：24 种武器（23 枪械 + 刀）的完整数值（价格、伤害、爆头倍率、护甲比、射速、弹匣、射程、散射、后坐力、开镜 FOV、移速缩放、阵营）。
- 来源注释：数值提取自 Valve `scripts/weapons.vdata_c`（2026-09-08），Source 单位以 0.0254 转米。
- 关键导出：`WEAPONS`、`WEAPON_ORDER`、`PRIMARY_WEAPONS`、`TEAM_LOADOUTS`、`WEAPON_ALIASES`、`normalizeWeapon(id)`、`getWeapon(id)`、`canTeamUseWeapon`、`defaultPrimaryForTeam`、`weaponSpeedScale`。

### equipment.js — 装备
- `EQUIPMENT`：护甲、头盔、拆弹器、高爆、闪光、烟雾、燃烧瓶/燃烧弹、诱饵。
- 导出：`UTILITY_IDS`、`teamUtilities`、`MAX_GRENADES=4`、`normalizeEquipment`、`getEquipment`、`canTeamBuyEquipment`、`equipmentPrice`、`grenadeCount`。

### skins.js / agents.js
- `DEFAULT_SKINS`、`getSkin`、`normalizeSkinLoadout`（皮肤）；`DEFAULT_AGENT_IDS`、`getAgent`、`normalizeAgentLoadout`（探员）。

## 3. 关键算法模块

### aim.js — 瞄准与确定性弹道
- `eyePosition(player)`：根据蹲伏量计算眼睛位置。
- `accuracyForShot(weapon, player, zoomLevel, penalty)`：综合站/蹲、移动（三次衰减 moving³）、跳跃、附加惩罚，返回 `{spread, inaccuracy, total, moving}`。
- `shotRng(shotId, pelletIndex)`：**确定性 RNG**——由 `shotId` 推导 LCG 种子，双端同种子产生相同随机序列，使本地预渲染弹道与服务器命中一致。
- `sampleShotDirection(yaw, pitch, accuracy, random)`：按 inaccuracy + spread 双圆盘抽样弹道方向。
- `bulletFireAngles(lookYaw, lookPitch, aimPunch)`：叠加后坐力视角偏移。

### physics.js — 移动与碰撞
- 常量：`PLAYER_RADIUS/PLAYER_BODY_RADIUS`、`STAND_HEIGHT/CROUCH_HEIGHT`、`GRAVITY`、`JUMP_SPEED`、`STEP_HEIGHT`、`JUMP_BUFFER_TIME`、`SV_FRICTION/STOPSPEED/ACCELERATE/AIRACCELERATE` 等（Source 移动参数）。
- `initPhysics(positions, surfaceMaterials)`：用 `three-mesh-bvh` 建立地图碰撞。
- `createPlayerState(spawn)` / `hullFor(p, height)` / `raycastWorld` / `raycastWorldSurfaces` / `floorHeight` / `getGroundMaterial` / `raycastWorldContact`。
- `stepPlayer(p, input, dt)`：模型移动、跳跃、重力、走/跑、斜坡、台阶支撑。
- `stepCorpse(p, dt)`：尸体物理。
- `resolvePlayerBodyCollision(p1, p2)` / `resolvePlayerAgainstOthers` / `resolveAllPlayerCollisions`：玩家间实体胶囊碰撞与推挤（防穿模）。

### movement-commands.js — 移动指令流
- `MOVEMENT_HZ=60`、`MAX_MOVE_BATCH/MAX_MOVE_QUEUE`。
- `movementState`、`sanitizeMoves`、`simulateMove`、`class MovementStream`（客户端打包移动指令、服务端接收并重放以对齐确定性移动预测）。

### cs2-settings.js — CS 设置换算
- `CS2_BASE_FOV=90`、`CS2_MOUSE_YAW/PITCH=0.022`、`AWP_ZOOM_FOVS`。
- `cs2FovToVertical` / `cs2FovToHorizontal`：CS 4:3 基准 FOV → 垂直/水平 FOV。
- `mouseRadiansPerCount`：每鼠标计数角度（含开镜独立灵敏度）。
- `decodeCrosshairCode(code)` / `normalizeCrosshair` / `DEFAULT_CROSSHAIR`：CS 准星分享代码解码。

### player-timeline.js
- `PlayerTimeline`、`MAX_REWIND_MS`：位置回溯，服务端在开枪瞬间用历史姿态做延迟补偿（最多 200ms 回溯）。

### match-rules.js
- `MATCH_RULES`、`TEAM_IDS`、`oppositeSide`、`botCount`。
- `defuseDecision(scores, roundsPlayed)`：确定常规/加时胜负、换边、重置资金。
- `grenadeMode` / `grenadeStrength`：投掷模式（远投/低抛/中投）→ 力度。

### weapon-ballistics.js
- 弹道衰减、穿透能力（口径）等参数，供服务端 `traceBullet` 与客户端特效共用。

### melee.js
- `KNIFE`（`firstSlash`、`stabDamage`、`slashRange`、`stabRange`）、`traceKnife`、`knifeDamage`、`knifeInterval`。
