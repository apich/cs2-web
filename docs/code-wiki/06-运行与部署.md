# 06 · 运行与部署

## 1. 环境要求

- **Node.js >= 22.12.0**（项目 uses ESM、top-level await、Node 原生测试）
- **npm**
- **现代浏览器**：支持 WebGL2 与 Pointer Lock 的 Chrome / Edge（手机用触屏）

源码（代码）与大体积运行资源（3D 地图/模型/音效）分开管理，资源需额外拉取。

## 2. 脚本（package.json）

| 命令 | 作用 |
| --- | --- |
| `npm ci` | 安装依赖 |
| `npm run assets:fetch` | 从 CDN 拉取大体积 3D/音效资源（已存在自动跳过） |
| `npm run assets:check` | 校验资源完整性（`--check`） |
| `npm run dev` | Vite 开发服务器（`0.0.0.0:5178`，严格端口） |
| `npm start` | 启动权威服务器 `node server/index.js` |
| `npm run build` | `build-asset-manifest.mjs` 后执行 `vite build` |
| `npm test` | `node --test tests/*.mjs` 运行回归测试 |

## 3. 本地运行模式

### 3.1 首次准备
```bash
npm ci
npm run assets:fetch
```

### 3.2 选项 A — 开发模式（推荐，HMR）
```bash
# 终端 1：权威游戏服务器
npm start

# 终端 2：Vite 前端
npm run dev
```
- 打开 `http://localhost:5178/`。
- Vite 把 `/ws`、`/api`、`/health` 代理到 `127.0.0.1:3000`（见 `vite.config.js`）。
- 支持**原地 HMR**：`client/main.js` 末尾 `import.meta.hot.accept([...])` 声明了可直接热替换的模块（`aim.js`、`weapons.js`、`recoil-tables.js`、`crosshair.js`、`hud.js`、`audio.js`、`footstep-system.js`、`controls.js`），改动这些文件无需刷新、无需重新加载 200MB 地图。

### 3.3 选项 B — 生产单包模式
```bash
npm run build
npm start
```
- 打开 `http://localhost:3000/`。
- Node.js 服务端同时托管 `dist/`（静态页面，优先）与 `public/`（素材），并提供 `/ws`。
- Windows 可双击 `Start-Game.cmd` 启动、`Stop-Game.cmd` 停止（资源就绪后）。

## 4. 测试

```bash
npm test
```
- 使用 Node 原生 `node:test`，匹配 `tests/*.mjs`。
- 套件覆盖 **303 项回归**：命中盒几何/爆头、急停衰减、随机弹道、脚步声学、实体碰撞、跳跃/输入边沿、武器与购买、双客户端同步、爆破状态机、机器人 AI、资源生命周期等。
- 各测试文件独立，`tests/fixtures/` 提供移动地形 JSON 等固定样本。

## 5. 部署（deploy/）

公网部署需 HTTPS 与 WebSocket 转发。`deploy/` 提供：

| 文件 | 用途 |
| --- | --- |
| `dust2-web.service` | systemd 服务单元 |
| `dust2-web.location.conf` | Nginx 路由（含 `/ws` 升级） |
| `*.py`（`package-release.py`/`activate-release.py`/`package-delta.py` 等） | 发布打包、增量、激活、回滚 |
| `new-server.py` / `NEW_SERVER.md` | 新服务器初始化 |
| `verify-*.mjs` | 发布产物/公网校验 |

新主地址 `cs2.duskrain.cn` 使用独立域名根路径；旧站使用 `/dust2/` 路由（`redirect-old-dust2.py`）。

## 6. 环境变量与服务配置

`server/index.js` 读取：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP/WS 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `MAX_ROOMS` | `12`（clamp 1–100） | 最大并发房间数 |
| `DUST2_RELEASE` | `local` | 发布版本标签，输出到 `/health` |

健康检查端点：`GET /health` → JSON（服务名、tick 率、房间数、玩家数、内存、性能快照）。

## 7. 端口与代理汇总

| 端点 | 用途 |
| --- | --- |
| `:3000` | 生产 Node 服务器（HTTP 静态 + `/ws` + `/health`） |
| `:5178` | Vite 开发服务器（前端） |
| `/ws` | WebSocket 游戏连接（dev 下由 Vite 代理到 3000） |
| `/health` | 健康检查 |
